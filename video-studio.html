☑️ צ'קליסט ידני
סמן ידנית מה שהסרטון עומד בו.
🤖 בדיקה חכמה + הערכת סיכוי (Claude)
Claude בודק את "החוקים הרכים", נותן ציון איכות, מעריך סיכוי הצלחה ומציע שיפורים. ככל שתזין יותר תוצאות בפועל, ההערכה מדויקת יותר.
📊 תוצאות בפועל
מלא אחרי שהסרטון עלה. הנתונים האלה מלמדים את המערכת מה עובד אצלך.
🧱 שלד התבנית
הבלוקים שכל סרטון בנוי מהם, לפי הסדר. לכל בלוק אפשר להוסיף הנחיה קצרה שתופיע בעורך.
📏 חוקי מלל אוטומטיים
חוקים דטרמיניסטיים שנבדקים מקומית ומיידית על התסריט. "חובה" = כשל אדום, "רצוי" = אזהרה צהובה.
🤖 חוקים רכים (ל-Claude)
כללים שקשה לבדוק אוטומטית — Claude יעריך כל אחד. למשל: "ה-HOOK יוצר סקרנות אמיתית ולא קליקבייט".
🧠 בסיס ידע / יוצרי רפרנס
עקרונות ותובנות שנכנסים ל"מוח" של Claude בכל בדיקה חכמה — בנוסף למסגרת המקצועית המובנית. הוסף כאן טיפים מיוצרים שאתה מעריך (למשל @iamchrischung), ניסוחי HOOK שעבדו, או כללים אישיים.
☑️ פריטי צ'קליסט ידני
שאלות כן/לא שתסמן ידנית לכל סרטון.

🔑 חיבור ל-Claude API

הזן את מפתח ה-API שלך מ-Anthropic Console. המפתח נשמר מקומית בדפדפן בלבד ומשמש רק לבדיקה החכמה והערכת הסיכוי.

📥 ייבוא סרטונים

בחר קובץ JSON או הדבק ידנית. כל סרטון: title, blocks (לפי שמות הבלוקים), ו-actual (הנתונים). הסרטונים יתווספו לספרייה.
